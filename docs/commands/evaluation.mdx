## Run it

```bash
python scripts/08_evaluate.py --config configs/train_phase2.yaml \
    --ckpt artifacts/thinkspark-v2-350m/phase2/final \
    --frames "data/frames_val/*.jsonl"
```

<Note>
Use a **held-out** frame shard here — never the exact shard(s) you trained on. A quick way
to get one: hold back one or two of your `data/plan/plan_part*.jsonl` shards from
generation/training entirely, or split off a fraction of scenarios before Phase-2 training.
</Note>

## What to check if a bar fails

| Symptom | Likely cause | Where to look |
|---|---|---|
| `BARGE_HARD` low recall | too few real-barge examples, or focal `gamma`/`alpha` mistuned | `configs/train_phase2.yaml → focal_gamma`, re-check [distribution plan](/commands/data-generation) |
| High false-barge rate | `barge_lookalike` bucket under-represented or mislabeled | `python scripts/05_validate_data.py` — check `barge_lookalike` resolves to `CONTINUE` |
| `PREFETCH_LLM` low F1 | ambiguous near-end prosody in training data | inspect `prefetch` bucket scenarios in `data/scenarios/scenarios_all.jsonl` |
| Latency p95 too high | not using bf16 / no grad-checkpointing at inference, or CPU-only | confirm `--device cuda` path is used; see [Inference](/commands/inference) |
| VAD-F1 low | Phase-1 under-trained or free corpus not gender-balanced | revisit [Preprocessing](/commands/preprocessing) and Phase-1 epochs |
